# 导航重构设计方案

Version: v1.0

Status: Draft

Owner: UI / Frontend Engineer

---

## 1. 整体架构

```
当前：单页滚动式
/  →  Hero → 特性 → 模型 → 定价 → CTA → FAQ → Footer

改为：多页路由
/       → 首页（Hero + 特性 + 定价 + CTA + FAQ）
/models → 模型广场（模型展示独立页）
/docs   → 文档中心（产品简介 + 快速入门 + API + FAQ）
```

---

## 2. 导航栏变化

### 现在（锚点导航）

```
[Logo]  [产品特性] [支持模型] [全球架构] [定价方案] [常见问题]  [登录控制台]
```

### 改为（路由导航）

```
[Logo]  [🏠 首页] [🧩 模型广场] [📄 文档中心]    [登录控制台]

         ┌─────────┐
         │ 首页      │  ← 当前高亮
         ├─────────┤
         │ 模型广场  │  ← 路由跳转到 /models
         ├─────────┤
         │ 文档中心  │  ← 路由跳转到 /docs
         └─────────┘
```

- 导航不再使用锚点滚动
- 点击「首页」回到 `/`，整个页面重新显示所有区块
- 高亮状态由当前路由决定

## 4. 路由设计

```ts
// src/router/index.ts
routes: [
  { path: '/',        name: 'home',   component: HomePage },
  { path: '/models',  name: 'models', component: ModelsPage },
  { path: '/docs',    name: 'docs',   component: DocsPage },
]
```
