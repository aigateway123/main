## 交互说明

| 元素 | 行为 |
|------|------|
| **树形目录** | 点击一级分类（▶/▼）展开/收起子项 |
| **子项** | 点击后右侧内容区切换对应内容 |
| **当前项** | 蓝色高亮 + 左侧蓝条指示 |
| **右侧内容** | 根据左侧选择动态切换，同一页面内切换（无路由跳转） |
| **滚动** | 左侧目录固定（sticky），跟随页面滚动；右侧内容独立滚动 |

## 目录数据结构

```ts
interface DocMenuItem {
  title: string        // 分组名称
  icon?: string        // 图标名
  children: {
    id: string         // 唯一标识
    title: string      // 页面标题
  }[]
}
```

页面内容用静态数据管理：

```
src/data/docs/
├── index.ts           ← 目录树 + 所有页面内容的聚合导出
├── intro.ts           ← 产品简介
├── quickstart.ts      ← 快速入门
├── api.ts             ← API 接口
└── faq.ts             ← 常见问题
```
