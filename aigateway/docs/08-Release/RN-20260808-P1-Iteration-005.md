## 6. 已知限制与注意事项

1. **明文密码安全**：按业务确认，`plain_password` 明文存储供管理端查看，存在数据库泄露风险；访问控制已通过独立权限点 `admin:user:view_password` 隔离，仅拥有该权限的角色可见。
2. **新账号模型权限**：新创建的账号默认无任何模型授权，需管理员在「账号详情 → 编辑模型权限」弹窗中勾选授权后才可见可用。
3. **存量账号密码**：迁移前创建的账号明文密码为空（显示 `-`），可通过「重置」功能设置新密码后可见。
4. **模型编辑权限**：模型编辑/管理仍仅 `admin:model:manage` 角色可操作，普通账号天然无法编辑被授权模型。

---

## 7. 后续建议

- 可考虑对 `plain_password` 做可逆加密（AES）替代明文存储，兼顾管理端查看与安全性。
- 模型权限授权粒度目前为「模型级」，后续可评估扩展 Provider 级或额度级权限。
- 权限点较多，建议在 Admin 角色管理页补充权限点分组与描述展示。
