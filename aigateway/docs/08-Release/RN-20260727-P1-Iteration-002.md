## 2. 迭代目标

基于 AI Gateway MVP 已具备的产品能力，设计并上线面向公众的门户网站（公司官网 / Landing Page），打通从品牌展示到 Admin 控制台的转化路径。

### 关键目标

- **G1**: 上线 Nova AI Gateway 门户网站 MVP，展示产品的核心能力和价值主张
- **G2**: 提供"登录控制台"入口，打通从官网到 Admin 的跳转路径
- **G3**: 建立品牌基础视觉体系
- **G4**: MVP 首月 ≥ 100 UV，≥ 20 次跳转到 Admin 控制台

## 5. 技术方案

### 项目结构

```
portal/
├── src/
│   ├── components/
│   │   ├── Header.vue          # 导航栏
│   │   ├── HeroSection.vue     # Hero 主视觉区
│   │   ├── WhySection.vue      # 产品优势
│   │   ├── ModelsSection.vue   # 模型展示
│   │   ├── InfrastructureSection.vue  # 基础设施
│   │   ├── CTABanner.vue       # 行动召唤
│   │   ├── FAQSection.vue      # 常见问题
│   │   └── FooterSection.vue   # 底部
│   ├── data/
│   │   ├── features.ts         # 特性数据
│   │   ├── models.ts           # 模型数据
│   │   ├── infrastructure.ts   # 基础设施数据
│   │   └── faq.ts              # FAQ 数据
│   ├── App.vue
│   └── main.ts
├── index.html
├── package.json
├── vite.config.ts
├── tailwind.config.js
├── tsconfig.json
└── postcss.config.js
```

### 技术栈

- Vue 3 + TypeScript (Composition API, `<script setup>`)
- Vite 5
- Tailwind CSS 3
- 无后端依赖（所有数据为静态数据）
