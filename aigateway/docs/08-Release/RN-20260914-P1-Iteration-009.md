## 3. 兼容性、影响面与约束

| 项 | 结论 |
|----|------|
| 变更性质 | **纯新增**（ADD COLUMN + 可选请求字段 + 新增响应字段），无 breaking change |
| 存量数据 | 升级后存量模型一律 `false`，无数据搬运、无 `UPDATE` 语句，**不需要迁移前备份** |
| 对外契约 | `GET /v1/models`（OpenAI 兼容）**不暴露**该字段（QA TC-21 / TC-44：`grep -c supportsMultimodal` = 0）；Anthropic 侧无独立 models 端点（TC-22 N/A） |
| 筛选查询参数 | `supportsMultimodal` 仅存在于 Admin 接口 `GET /api/v1/models`；详情接口 `GET /api/v1/models/{id}` 不受影响。非布尔值返回 `400 VALID001`（TC-41） |
| 推理链路 | 本期字段**仅作标记**，网关不做图片输入校验、拦截或协议改造；`/v1/chat/completions` 行为与改动前一致 |
| 客户端 | 新增响应字段不影响既有客户端（JSON 多字段默认忽略） |
| ⚠️ 回滚顺序约束 | 新代码在 `model_repo_pg.go` 中**显式查询** `supports_multimodal` 列，因此**新代码运行期间绝不能执行 down.sql 删列**（会导致模型相关接口全线 500）。详见 §8 |

## 8. 回滚 Runbook

> 核心约束：**新增列只为纯增量，代码回退后旧版本完全不引用该列**（旧代码列清单不含 `supports_multimodal`），因此**回滚默认不删列**。

| 场景 | 操作 | 数据库动作 |
|------|------|-----------|
| **推荐**：后端 / 前端逻辑异常 | `git revert 6be532d 859cc68 98422d4`（由新到旧；或 `git checkout <上一版本commit>`）→ 服务器 `git pull --ff-only` → 重跑 `bash infra/scripts/deploy.sh` | **保留列**（无结构变更、无数据丢失，旧代码忽略该列，保留无害） |
| 仅「多模态输入」筛选异常（标记字段正常） | `git revert 6be532d 859cc68`（由新到旧）→ 重跑 `deploy.sh` | 无（筛选为纯代码变更，无结构变更、无迁移） |
| 仅 Admin 前端异常（后端正常） | 仅回退 Admin 提交（`git revert 6be532d`，必要时含 `98422d4` 的 UI 部分）→ 重跑 `deploy.sh`（重建 admin） | 无 |
| 仅单个模型标记值配错 | 直接在 Admin 表单改回并保存 | 无 |
| 确需彻底删除该字段 | **必须两步且顺序不可颠倒**：① 先回退代码并重建 gateway（旧代码生效）→ ② 再执行 `backend/migrations/202609140001_add_model_multimodal.down.sql` | `DROP COLUMN IF EXISTS supports_multimodal` |
| 处在中间态（列存在但无版本记录） | 见 §7.4 第二行 | 补写 `schema_migrations` 记录或回退代码 |

**禁止事项**

1. ❌ **新代码运行期间执行 down.sql 删列** —— 新代码显式查询该列，删列后模型接口全线 500。
2. ❌ **手工删除 `schema_migrations` 记录或手工重跑 up.sql** —— `up.sql` 非幂等（`ADD COLUMN` 无 `IF NOT EXISTS`），列已存在时会报错并导致 gateway 启动失败。
3. ❌ **回滚后重新升级时预期数据恢复** —— 本次无数据搬运，无需也无法"恢复"；`supports_multimodal` 值随列删除一并消失，重新升级后全部回到 `false`。

**回滚验证**

```bash
curl -s http://127.0.0.1:8080/api/v1/models -o /dev/null -w '%{http_code}\n'                   # 401（受保护，非 500）
docker compose logs gateway | tail -n 50                                                       # 无 supports_multimodal 相关报错
```
