## 5. 设计变更记录

### 5.1 从 MVP 到 P1 的关键变更

| # | 变更内容 | 原因 | 涉及模块 |
|:-:|---------|------|---------|
| 1 | 注册接口废弃（返回 410） | 学生改为 Admin 创建 | Auth |
| 2 | 新增角色/权限管理 | 支持 RBAC 权限控制 | RBAC |
| 3 | 模型定价支持 time_based 模式 | 峰谷计价需求 | Billing |
| 4 | 新增行锁扣费（SELECT FOR UPDATE） | 确保并发扣费一致性 | Billing |
| 5 | 新增 SSE 流式计费 | 流式请求正确计费 | Billing |

### 5.2 关键决策（ADR）

| ADR | 决策 | 原因 |
|-----|------|------|
| ADR-001 | 行锁（SELECT FOR UPDATE）同步扣费 | 学生并发场景可控，实现简单 |
| ADR-002 | Redis RBAC 缓存 + 空值缓存 TTL 30s | 防缓存穿透，提升性能 |
| ADR-003 | SSE 流式最后一块解析 usage 计费 | 避免逐块累加误差，api 成本兼容 |
