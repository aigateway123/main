## 5. 已知限制与注意事项

1. **qwen3.8-max-preview**：阿里云百炼仅 Token Plan 订阅可用；当前生产 千问 Provider 为标准 DashScope 端点，调用该模型返回 403 access_denied。如需上线，须新增 Token Plan Provider（`token-plan.cn-beijing.maas.aliyuncs.com` + 专属 Key）并将模型改绑，或改用 `qwen3.7-max`。
2. **MiniMax-M3**：思考模式默认开启（adaptive）。生产使用原生端点 `/v1/text/chatcompletion_v2`，建议改用官方 OpenAI 兼容端点 `https://api.minimaxi.com/v1/chat/completions`；客户端需传 `max_tokens`（≥1024）或显式关闭思考，否则可能出现「调通但返回空内容」。
3. **密钥管理**：`backend/scripts/restore_local_dev.sql` 含真实 API Key（与 setup_all.py 相同），已推送远程仓库；建议轮换密钥并将密钥移出版本库（改环境变量注入）。
