## 2. 功能范围

| # | 功能 | 状态 |

| 1 | 新增 Anthropic 兼容入站端点 `POST /v1/messages`（及 `/api/v1/messages`），认证兼容 `x-api-key` 与 `Authorization: Bearer` | ✅ |

| 5 | 计费/配额/日志复用现有链路：Anthropic `input/output_tokens` 与 OpenAI `prompt/completion_tokens` 双格式解析 | ✅ |

## 6. 部署计划

| 步骤 | 操作 |
|------|------|
| 1 | 代码提交 + push 至 GitHub 远程（main） |
| 2 | ECS `git pull` |

- DeepSeek/Kimi 需先更新为有效 Key

## 7. 已知限制

1. **多模态（image 内容块）完整双向转换不在本次范围**（文本 + tools 完整支持）
2. **DeepSeek anthropic 端点流式可能回退为 JSON**：适配层已按 Content-Type 兼容，但计费以实际解析结果为准
3. **智谱 Anthropic 端点对购买 Coding Plan 账号的额度走套餐、需加白**：以账号实际权限为准
4. **响应 thinking 块**：ANT 入 → OAI 出 时丢弃 thinking 块仅保留 text；ANT 入 → ANT 出 透传保留

---

## 8. 回滚预案

| 场景 | 操作 |
|------|------|
| 迁移 013 失败 | 执行 down.sql 删除两列，重启 gateway |
| 新端点异常 | 回滚代码：`git revert <commit>` 或 `git checkout <上一版本>` + rebuild |
| Provider 协议配置错误 | Admin 后台调整协议/认证方式，无需回滚代码 |
| 存量调用受影响 | `protocol_type` 默认 `openai` 向后兼容，存量 Provider 无感 |
