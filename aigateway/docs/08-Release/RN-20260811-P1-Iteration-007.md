## 4. 已知限制

1. **count_tokens 为估算口径**：网关不持厂商 tokenizer，估算值供 SDK 预估计费参考，实际计费以 Provider usage 为准
2. **智谱 API Key 已在仓库多脚本硬编码**（历史遗留）：建议轮换 Key 并统一改环境变量注入（本次新增脚本已改为 `ZHIPU_API_KEY` 环境变量）
3. **多模态 / beta 头功能不在本次范围**
