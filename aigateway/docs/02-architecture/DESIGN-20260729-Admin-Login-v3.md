## 设计目标

统一 Portal 官网与 Admin 后台的视觉语言，登录页作为两者的过渡页，既要体现品牌感，又要保持工具页面的简洁高效。

## 方案 A：品牌融合（推荐）

**定位**：Portal 与 Admin 的中间态，品牌统一但克制

## 风格对比

| 维度 | 方案 A (品牌融合) | 方案 B (轻量 Portal) | 方案 C (极简高级) |
|:----|:---------------:|:------------------:|:--------------:|
| Portal 关联度 | 中 (Logo + 蓝色) | **高** (渐变 + 光晕) | 低 (仅文字) |
| Admin 工具感 | **中** | 低 | **高** |
| 开发成本 | 低 (改 1 文件) | 低 (改 1 文件) | 低 (改 1 文件) |
| 独特性 | 平衡 | 品牌感最强 | 最安全不出错 |
| 视觉冲击 | 适中 | **较强** | 安静 |

---

## 我的推荐

**方案 A** — 理由是：
1. Logo 用了 Portal 的蓝靛渐变底板，品牌统一
2. 卡片式表单适合后台（vs 方案 C 无卡片显得太空）
3. 按钮用 Portal 主色 blue-600 而非渐变，克制且干净
4. 比方案 B 轻量，不会过度设计
