## 品牌插图建议

左栏的插图可以用以下方式生成（用 text_to_image API）：

```
Prompt:
"A futuristic AI gateway abstract illustration, glowing blue and indigo 
neon lines connecting various AI model icons (OpenAI, Claude, DeepSeek), 
minimalist tech style, dark blue background, mesh network visualization, 
clean lines, no text, professional SaaS aesthetic, 4k quality"
```

效果类似：
- 深蓝背景上发光的 AI 模型连接网络图
- 抽象的网关/路由节点示意
- 极简科技风线条

## 响应式

```
桌面 (>1024px):   左栏 55% + 右栏 45%，并排显示
平板 (768-1024px): 左栏 45% + 右栏 55%，缩小插图
移动端 (<768px):   隐藏左栏，右栏全屏显示
                   Logo + 品牌名显示在表单上方
```

## 和 Portal 的关系

| 元素 | 来源 |
|------|------|
| 左栏渐变背景 | Portal CTA Banner 的 `from-blue-600 to-indigo-700` 渐变 |
| Logo 蓝靛底板 | Portal Logo 规范 |
| "Nova" 品牌名 + "AI Gateway" | Portal Header 的品牌文字 |
| 品牌关键词列表 | 从 Portal 的 Why Section 提炼 |
| 右栏白色背景 | Admin 现有风格 |
| 蓝色按钮 | Portal 主色 blue-600 |
