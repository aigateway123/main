# Admin 登录页 — UI 重新设计规范 v2

Version: v2.0

Status: Draft

Owner: Designer / Frontend Engineer

Last Updated: 2026-07-29

Design Direction: **简洁留白高级感（Stripe 风格）**

---

## 1. 设计方向

### 风格定位

极简、留白、精致。参考 Stripe / Linear 等产品的登录页设计语言。

| 关键词 | 说明 |
|--------|------|
| 留白 | 大量负空间，呼吸感 |
| 精致 | 纤细边框、柔和阴影、小字号精细排版 |
| 安静 | 无装饰光晕、无渐变、无强烈色彩冲击 |
| 聚焦 | 视觉完全集中在登录表单上 |

### 与 Portal 的关系

不与 Portal 共用装饰语言（渐变/光晕/大圆角），而是在 **品牌色** 和 **字体** 层面保持一致。

## 3. 具体改动

### 页面背景
- `bg-white` — 纯白，无任何装饰
- 上下左右大量留白

### 品牌 Logo
- 极小，居中
- 去掉渐变底板，改为纯文字
- 字号 `text-sm font-semibold text-slate-400 tracking-widest uppercase`
- 字母间距宽松，类似 Stripe 的 "STRIPE" 品牌文字

### 表单标题
- `登录到控制台` — `text-2xl font-semibold text-slate-900 tracking-tight`
- 简洁直接，不加副标题

### 输入框
- 极简风格
- 边框: `border border-slate-200` (1px, 非常淡)
- 圆角: `rounded-lg` (8px, 适中)
- 高度: `h-10`
- Focus: `border-slate-400 ring-0` — 只加深边框，不加光环
- 标签: `text-sm font-medium text-slate-700`，左对齐
- 占位符: 不要

### 登录按钮
- `bg-slate-900 text-white` — 纯黑色按钮（Stripe 标志性设计）
- 圆角: `rounded-lg`
- 高度: `h-10`
- Hover: `bg-slate-800`
- 无阴影
- 无上浮动效
- 无渐变

### 错误提示
- `text-sm text-red-600` — 纯文字，无背景框
- 位置在按钮上方

### 忘记密码
- `text-sm text-slate-400 hover:text-slate-600`
- 居中，在按钮下方

### 底部
- `text-xs text-slate-300`
- `© Nova AI Gateway 2026`
- 居中，极小

## 4. 对比：Portal 风格 vs Stripe 风格

| 元素 | Portal 风格 (v1) | Stripe 风格 (v2, 选定) |
|------|-----------------|----------------------|
| 背景 | 灰色 + 蓝靛光晕 | **纯白** |
| 卡片 | 白色卡片 + 大阴影 | **无卡片，直接居中** |
| Logo | 蓝靛渐变底板 + 图标 | **极小纯文字 "Nova"** |
| 标题 | Nova AI Gateway 双色 | **登录到控制台** |
| 输入框 | rounded-xl + 蓝色光环聚焦 | **rounded-lg + 纯边框加深** |
| 按钮 | 蓝靛渐变 + hover 上浮 | **纯黑 + hover 变深** |
| 风格 | B2B SaaS 品牌官网感 | **Stripe 式极简工具感** |
