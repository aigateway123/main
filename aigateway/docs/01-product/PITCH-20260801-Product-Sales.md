## 1. 一句话定位

> **Nova AI Gateway —— 面向企业和开发者的「大模型统一接入平台」。**
> 一个 API Key，一套 OpenAI 兼容接口，即可调用全球主流大模型，并内置智能路由、故障自动切换、按量计费与成本管控能力。

---

## 2. 市场背景：多模型时代已经到来

### 2.1 行业趋势

| 年份 | 企业的真实需求 |
|:----:|---------------|
| 2023 | "我要接 GPT" |
| 2024 | "我要接 GPT + Claude" |
| 2025 | "我要接十几个模型" |
| 2026 | "我要根据成本、速度、效果**自动选择模型**" |

AI 行业已进入 **Multi-Model（多模型时代）**。企业需要的不是某个模型的 API，而是 **AI Infrastructure（AI 基础设施）**。

### 2.2 企业正在面临的真实痛点

| 痛点 | 影响 |
|------|------|
| **模型越来越多** | OpenAI、Claude、Gemini、DeepSeek、Qwen、GLM… 逐个适配成本高 |
| **API 不统一** | 各家参数、返回值、能力各不相同，业务代码与厂商强绑定 |
| **成本越来越高** | 不同模型价格差异巨大，缺乏统一视角管控 |
| **稳定性不足** | 单一 Provider 故障直接导致业务中断 |
| **权限混乱** | 多团队、多项目共用账号，无法精细管理 |
| **日志缺失** | Token 消耗与问题定位无法追踪 |

---

## 3. 解决方案：Nova AI Gateway 核心能力

### 3.1 统一 API，一次接入全部模型

- 完全兼容 **OpenAI Chat Completions** 接口规范，Python / JavaScript / Go SDK 及 cURL 可直接使用
- 接入只需改 2 个参数：`api_key` + `base_url`，**5 分钟内完成接入，业务代码零改造**

```python
from openai import OpenAI

client = OpenAI(
    api_key="nv_sk-xxxxxxxxxxxxxxxx",
    base_url="https://api.novagateway.ai/v1",
)
```

### 3.2 多 Provider 管理与故障自动切换

- 同一模型可绑定多个 Provider，配置优先级 / 权重
- 主用 Provider 失败时**自动切换备用**，业务无感、不中断
- 路由策略：最低价格 / 最快速度 / 权重分配 / 轮询 / 失败切换

### 3.3 精确计费与成本管控

- 输入 / 输出 Token **分开计价，精确到 Token**
- 流式请求（SSE）自动解析 `usage` 字段完成计费，**不遗漏任何一次调用**
- 额度扣减采用行级锁保证**强一致**，绝不超扣

### 3.4 用量统计与成本报表

- 每次调用自动记录：模型、Provider、Token、费用、延迟、状态
- 控制台提供用量汇总、明细查询与**成本报表导出**
- 收入、成本、利润按用户 / 模型 / Provider 全维度可查

### 3.5 极致性能（架构级保证）

| 指标 | 目标 |
|------|------|
| Gateway 主链路 | < 10ms（不含模型推理） |
| Policy Engine 单次校验 | < 2ms |
| Router 路由决策 | < 2ms |
| 主链路数据库访问 | 99% 请求不访问数据库（Redis 缓存） |

日志、成本、统计全部**异步化**处理，不阻塞主链路请求。

## 5. 客户价值与 ROI

### 5.1 直接降本

- 通过智能路由 + 成本优化建议，将高频低价值调用（普通聊天、摘要）切换到高性价比模型
- 示例：GPT 用于普通聊天 12,000 次 → 改用 DeepSeek，预计**每月节省 ¥3,800**
- 峰谷分时计价：夜间批量任务自动走低谷价格

### 5.2 降低开发成本

- 一次接入全模型，避免 N 家厂商 SDK 适配与维护
- OpenAI 兼容，现有代码零改造迁移

### 5.3 降低业务风险

- 多 Provider 故障自动切换，**单一厂商故障不再中断业务**
- 行级锁强一致扣费，账目清晰可审计

### 5.4 目标客户价值分层

| 客户类型 | 核心价值 |
|---------|---------|
| 个人开发者 | 一个 Key 用所有模型 |
| 创业团队 / 小型公司（2~20 人） | 成本可视化、用量统计、智能路由、日志排查，ROI 清晰 |
| 企业客户 | 私有部署、安全合规、预算管控、审计、SLA 保障 |

## 8. 与原厂直连的价格对比

Nova AI Gateway **不赚取 API 差价**：平台公示的模型单价与原厂直连一致，增值点在于消除原厂直连的隐性成本（多账号、多充值、多适配、无容灾、无优化）。

### 8.1 综合成本对比

| 维度 | 直接接入原厂 | 通过 Nova AI Gateway |
|------|------------|---------------------|
| 模型单价 | 各厂商官网价 | **同价透明，无 SaaS 加价**（Portkey 等加价 10~30%） |
| 账号与充值 | 每家厂商独立注册、充值、管理额度 | 一个账号、一个 API Key 覆盖全部模型 |
| 接入成本 | 每家厂商一套 SDK、一套适配开发 | 一套 OpenAI 兼容接口，5 分钟接入，零改造 |
| 故障容灾 | 单点依赖，厂商故障即业务中断 | 多 Provider 自动故障切换，业务无感 |
| 成本优化 | 无，全价调用 | 智能路由自动选最低价 Provider + 峰谷分时计价 |
| 用量与报表 | 各厂商独立控制台，无法统一比对 | 统一成本报表，收入 / 成本 / 利润全维度可查、可导出 |

### 8.2 模型价格示例（同模型同价，无加价）

| 模型 | 原厂直连 | Nova AI Gateway |
|------|---------|:---------------:|
| GPT-5.6 Terra | $2.5 / $15 每 M Tokens | $2.5 / $15，**同价** |
| DeepSeek V4 Pro | ¥6 / ¥12 每 M Tokens | ¥6 / ¥12，**同价** |
| DeepSeek V4 Flash | ¥1 / ¥2 每 M Tokens（谷时段更低） | **峰谷计价**，夜间批量任务成本更低 |

### 8.3 量化节省示例

| 场景 | 原厂直连 | Nova AI Gateway | 节省 |
|------|---------|-----------------|:----:|
| GPT 用于普通聊天 12,000 次 / 月 | 全价调用 GPT | 智能路由切换至 DeepSeek | **约 ¥3,800 / 月** |
| 夜间批量任务（摘要 / 数据处理） | 全时段原价 | 峰谷计价走低谷价 | **成本再降 20~40%** |

> 说明：以上价格为平台公示参考价，实际价格以控制台配置和 `GET /v1/models` 返回为准。
