## 案例 1：材料学院——从 200 篇论文到实验方案

**场景：**

某材料课题组正在研究：

> “高温环境下新型复合材料的性能衰减机制”

博士生过去需要花 1～2 周：

- 搜索 Web of Science / Google Scholar
- 下载 100～200 篇论文
- 人工筛选相关论文
- 总结实验方法
- 整理不同材料配方
- 做 Excel 对比
- 最后写综述

现在通过 Nova：

**Step 1｜文献 Agent**

输入：

> “帮我分析近 5 年高温复合材料性能衰减相关研究，重点关注实验温度、材料配方、测试方法和性能指标。”

Agent 自动：

**检索 → 筛选 → 阅读 → 分类 → 总结**

最终输出：

| 维度         | AI整理结果 |
| ------------ | ---------- |
| 相关论文     | 186篇      |
| 核心论文     | 42篇       |
| 常用材料体系 | 7类        |
| 主流实验方法 | 5种        |
| 高频性能指标 | 12项       |
| 潜在研究空白 | 8个        |

然后继续：

> “基于这 42 篇论文，找出目前研究最少的 3 个方向，并给出实验设计建议。”

## 案例 2：计算机学院——博士生不会写实验代码

这个其实非常适合你的产品。

**场景：**

博士生拿到一篇论文：

> 《XXX模型在时间序列预测中的应用》

他需要复现论文实验。

传统流程：

**读论文 → 理解公式 → 找数据 → 写 Python → 调参 → Debug → 出图**

问题是：

> 会科研，不一定是程序员。

现在：

### Coding Agent

把论文 PDF + 数据集 + 实验要求交给 Agent。

Agent 自动完成：

```
论文
 ↓
提取实验方法
 ↓
生成实验计划
 ↓
创建 Python 项目
 ↓
生成数据预处理代码
 ↓
生成模型代码
 ↓
生成训练代码
 ↓
生成实验脚本
 ↓
运行实验
 ↓
分析结果
 ↓
生成论文图表
```

比如博士生只需要说：

> “按照论文 Section 4 的实验设计，帮我复现 Table 2。”

Agent 自动生成：

```
/data
/models
/train.py
/evaluate.py
/config.yaml
/experiments
/results
/README.md
```

然后：

> “把实验结果和论文原结果进行对比，告诉我差异在哪里。”

这就不是简单的“AI写代码”了。

而是：

**论文 → 实验 → 代码 → 结果 → 分析**

形成完整科研闭环。

LLM 在科学研究中的代码生成、数据分析已经是明确的研究应用方向，但现有研究也强调科研人员仍需要对方法和结果进行监督。

## 案例 3：生物/医学课题组——几十 GB 数据交给 AI 分析

这个场景更能体现 **Agent + 模型网关** 的价值。

比如：

> 某生物医学课题组完成了一批实验，产生大量 CSV / Excel / JSON 数据。

老师问：

> “帮我看看这批实验数据有什么异常。”

过去：

**博士生下载 → Python → Pandas → 清洗 → 统计 → Matplotlib → 写报告**

现在：

### Data Analysis Agent

直接：

**上传数据**

然后：

> “分析不同实验组之间的差异，并找出异常数据。”

Agent：

1. 自动识别字段
2. 检查缺失值
3. 检查异常值
4. 自动统计
5. 选择合适分析方法
6. 生成 Python / R 分析代码
7. 生成可视化
8. 输出分析报告

最后：

> **实验组 A 相比 B，指标 X 平均提升 18.7%，P 值……；同时发现 3 个异常样本，建议进一步复核。**

更重要的是：

**所有分析代码和模型调用记录都可以保留。**

这样科研人员不是拿一个“黑盒答案”，而是能追溯：

> **数据 → Code → Model → Result**

这对于科研可复现性尤其重要。

## 案例 6：论文 Agent——从实验结果到论文初稿

实验完成以后：

博士生把：

**实验数据 + 图表 + 实验代码 + 研究方法**

交给 Agent。

输入：

> “根据实验结果生成论文 Results 部分。”

**实验结果 → 图表解释 → 对比实验 → Ablation → Discussion**

然后再让 Reviewer Agent：

> “按照 IEEE 论文审稿人的标准帮我审一下。”

输出：

```
Major Issues
├── 实验样本量不足
├── 缺少 Baseline
├── 缺少 Ablation Study
└── 缺少统计显著性验证

Minor Issues
├── Figure 3 标注不清
├── Table 2 缺少单位
└── Reference 格式不统一
```

这就从：

**AI写论文**

升级成：

**AI科研协作团队。**
