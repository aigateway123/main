## 1. 背景与目标

### 1.1 背景

商业模式已升级为 **「AI 能力基础设施 + AI 员工 + 行业智能化解决方案」**，核心定位一句话：

> **让每一家中小企业，都拥有自己的 AI 员工**

业务分五层：`AI Gateway → AI Skills → AI 员工 → 行业 Agent → 私有化/订阅`，并形成一条客户升级路径：

```
Skill ¥499 → AI 员工 ¥19,800 → 私有化 ¥49,800 → 行业方案 ¥150,000
```

主攻两大行业：**工程 / 企业服务**（投标、合同、报表、知识库）与 **外贸 / 制造**（外贸销售、客服、知识库、经营分析）。

### 1.2 目标

将首页从「API 网关产品页」升级为「AI 能力平台 + AI 员工 + 行业解决方案」的**企业获客首页**，让访客一眼看懂：

1. 我们是谁 —— 不只卖 API，而是让企业拥有自己的 AI 员工
2. 我能买什么 —— 能力商城（Skill/专家团）→ AI 员工定制 → 行业解决方案
3. 怎么升级 —— 一条清晰的客户成长路径（含价格锚点）
4. 凭什么信 —— 用真实行业 Demo（投标顾问 / 爆款工厂 / 高校科研）证明能力

### 1.3 本次范围

- ✅ 首页整体信息架构重排 + 文案重构
- ✅ 新增「产品架构分层」「客户升级路径」「AI 员工定制」三个区块
- ✅ 行业解决方案区用新材料（投标顾问 / 爆款工厂）替换占位卡片
- ✅ 底部导航 / FAQ / 定价锚点与商业模式 V2 对齐

### 1.4 非目标

- ❌ 不做 AI 员工 / 行业方案独立落地页（后续迭代）
- ❌ 不重做设计系统与品牌色（沿用现有 Portal-Design-Spec）
- ❌ 不改 Skill 商城 / 专家团已有页面

## 4. 各区块详细设计

### ① Hero（重构）

- **主标题**：让每一家中小企业，都拥有自己的 AI 员工
- **副标题**：AI 能力商城 · 定制 AI 员工 · 行业智能化解决方案
- **支撑句**：底层 AI Gateway 统一接入顶级模型，上层 Skill / AI 员工 / 行业方案开箱即用
- **CTA**：`逛能力商城 →`（主）/ `了解解决方案`（次）
- **次要**：代码演示块保留但缩小/下移，或移入 ⑦「AI 基础设施」区块，Hero 改为产品矩阵氛围图
- **顶部徽章**：改为「AI 能力商城 · 19 个 Skill · 11 支专家团 · 行业解决方案」等运营信息

### ② 产品架构分层（新增 ProductLayerSection.vue）

五层纵向/横向可视化，每层：图标 + 名称 + 一句话 + 落地链接：

| 层 | 名称 | 一句话 | 链接 |
|----|------|--------|------|
| L1 | AI 基础设施 | 统一接入全品类模型，智能路由与成本管控 | `/#features` |
| L2 | AI 能力商城 | 即买即用的 Skill 与跨岗协作专家团 | `/skills` |
| L3 | AI 员工 | 学习企业资料、专属定制的 AI 员工 | `#ai-employee` |
| L4 | 行业解决方案 | 面向工程 / 外贸 / 内容等行业的一体化方案 | `/#solutions` |
| L5 | 私有化 / 订阅 | 数据安全、系统集成、长期运维服务 | 咨询 |

设计：横版阶梯（左侧向下箭头表示「从通用到行业」），或纵向列表卡片。

### ③ 客户升级路径（新增 UpgradePathSection.vue）

以「AI 投标」为例的可视化阶梯：

```
试用 Skill ¥499 → AI 投标员工 ¥19,800 → 企业私有化 ¥49,800 → 工程行业方案 ¥150,000
   ① 先买技能试试    ② 学习公司历史投标文件   ③ 数据不出企业    ④ 合同/项目/经营全家桶
```

每级：场景 + 触发理由 + 价格锚点。底部一句话：「用 Skills 获客，用 AI 员工赚钱，用行业 Agent 做大单。」

### ④ 能力商城入口（保留）

SkillEntryBanner + TeamEntryBanner 原样保留（19 技能 / 11 专家团计数自动更新）。

### ⑤ 行业解决方案（改造 SolutionsSection）

**数据**：`solutions.ts` 已有 3 个 online 方案，全部展示：

| 方案 | 定位 | 覆盖行业 |
|------|------|---------|
| 高校科研 Agent 解决方案 | 科研团队 | 高校 / 科研 |
| 内容增长工作台 · 爆款工厂 | 小红书/带货/电商内容增长 | 内容 / 电商 |
| AI 投标顾问 Agent · 投标作战指挥台 | 招标全流程作战 | 工程 / 企业服务 |

- 去掉 2 个「敬请期待」占位卡
- 卡片编排：2 大 + 1 侧，或 1 大 + 2 小
- 副标题与描述对齐商业模式 V2 行业叙事
- 底部链接「查看全部解决方案」

### ⑥ AI 员工定制（新增 AIEmployeeSection.vue）

区块 id=`#ai-employee`，承接 ② L3 锚点：

- **标题**：从「买一个技能」到「雇一个 AI 员工」
- **流程三步**：
  1. 客户提供：资质 / 历史投标文件 / 企业案例 / 产品资料
  2. 我们配置：专属 AI 员工（学习企业数据、匹配工作流）
  3. 持续服务：调优 + 知识库维护 + 月度服务
- **报价锚点**：基础版 ¥9,800 / 专业版 ¥29,800 / 企业版 ¥59,800+，另收 ¥500～5,000/月服务费
- **CTA**：联系定制（邮件 / 咨询）

### ⑦ AI 基础设施能力（改造 FeatureSection）

- 标题从「全能 API 网关」改为「底层 AI 基础设施」
- 描述强调「支撑上层全部能力的基座」而非「开发者工具」
- 6 卡可精简为 4 卡（多模型接入 / 智能路由 / 成本管控 / 安全合规），或保留 6 卡仅改文案

### ⑧ 定价（改造 PricingSection）

在现有 API 计费基础上，增加与商业模式 V2 对齐的报价卡（Skills / AI 员工 / 行业方案），或首页仅保留「能力商城 99-999 · AI 员工 9,800 起 · 行业方案 5 万起」的锚点条，完整报价表后续做定价页。

### ⑨ CTA / FAQ / Footer（改造）

- CTA 主文案：**「定制你的 AI 员工」**，次按钮「先逛逛能力商城」
- FAQ 增加：AI 员工怎么定制？和 Skill 什么区别？行业方案怎么合作？
- Footer 保持现状
