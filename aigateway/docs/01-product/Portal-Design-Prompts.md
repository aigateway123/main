## 设计提示词

```
为「Nova AI Gateway」设计一个现代化的 SaaS 门户网站。
Nova AI Gateway 是一个 AI API 网关平台，统一接入多种大模型。

需要设计的页面：
1. 首页（单页滚动式 Landing Page）：包含 Hero 区、产品特性、支持模型展示、
   技术基础设施、行动号召、常见问题、页脚
2. 定价页：三档套餐对比（入门版 / 专业版 / 企业版）

风格要求：简洁、专业、高端的 B2B SaaS 视觉风格。
主色调：蓝色和靛蓝色。Hero 区使用深色渐变背景，内容区交替使用浅色背景。
字体：现代无衬线字体。需同时适配桌面端和移动端响应式设计。

参考品质：Stripe / Vercel / Cloudflare 级别的官网质感。
```
