## 1. 背景与目标

### 1.1 背景

依据《商业模式规划V2.md》，XX AI（Nova AI Gateway）的业务定位从「大模型统一接入平台」升级为：

> **AI能力基础设施 + AI员工 + 行业智能化解决方案**

五层产品架构与五种收入来源：

```
Layer 5  Enterprise   私有化部署 / 数据安全 / 系统集成 / 运维服务
Layer 4  Industry AI  工程 / 外贸 / 制造 等行业解决方案（¥5万~50万+）
Layer 3  AI Employee  定制 AI 员工（¥9,800~59,800 + 月服务费）
Layer 2  AI Skills    AI 能力商城（¥29~4,999）
Layer 1  AI Infra     AI Gateway / Router / Cost Engine（API 差价 + SaaS 月费）
```

核心飞轮：**Gateway 获客降本 → Skills 商城变现 → 爆款 Skill → AI员工 → 行业 Agent → 私有化/订阅 → 更多数据与 Skills。**

### 1.2 本次迭代目标

将现有「Nova AI Gateway 平台」升级为可承载 **Skills / AI员工 / 行业解决方案** 的商业闭环平台，并明确分阶段路线图。

### 1.3 非目标

- 本规划不包含官网（Marketing Site）改版 —— 官网规划为下一迭代，单独输出。
- 本规划不包含 Layer 5 企业级全部能力（SSO / K8S / 多租户）的实现细节，仅给出依赖关系与排期。
- 本规划不包含 Agent Runtime / Memory / MCP 的完整实现 —— 按 MVP 原则以「Skill 运行时 = 配置化 Agent」轻量落地。

## 4. 迭代路线图（Roadmap 重排）

将原 P0~P6 路线图与商业模式 V2 对齐，重排为三个业务阶段（B1/B2/B3），原 P2 Policy Platform、P3 Developer Platform 能力已大部分提前交付，并入现有平台：

```
商业阶段   目标                      里程碑
─────────────────────────────────────────────────────────────
B1 (0~3月)  Skills 商业化闭环         Skill Marketplace 上线 + 首批 5~10 个 Skill 可售
B2 (3~6月)  AI 员工产品化             Top 3 爆款 Skill 升级为 AI 员工，可定制知识库
B3 (6~12月) 行业解决方案             聚焦 1 个行业（工程 or 外贸），私有化 + 交付 SOP
```

### 4.1 B1 — Skills 商业化闭环（0~3个月）【P0】

**目标**：验证「有人愿意为 Skill 付费」，跑通 Skill 从发布 → 购买 → 在线使用 → 收费的完整闭环。

| 模块 | 内容 | 优先级 |
|------|------|:---:|
| Skill 数据模型与 API | Skill 实体（名称/描述/图标/版本/定价/类型）、CRUD API、管理后台 | P0 |
| Skill Marketplace 前端 | Portal 新增「Skill 商城」：列表 / 详情 / 购买 / 我的 Skill | P0 |
| Skill 运行时（轻量 Agent） | 配置化 Agent 模板（系统提示词 + 输入表单 + 模型选择 + 输出），在线使用 + API 调用 | P0 |
| Skill 计费打通 | 复用 Billing：Skill 定价（一次性 / 订阅）、购买订单、退款 | P0 |
| 首批 Skills（5~10 个） | 从 Demo 优先产品化：AI投标顾问、AI外贸销售、AI合同审查、AI内容运营、AI数据分析等 | P0 |
| Skill 版本管理与作者 | 版本发布 / 更新 / 灰度、作者 / 平台分润（MVP 可仅平台自营） | P1 |

### 4.2 B2 — AI 员工产品化（3~6个月）【P1】

**目标**：把最畅销的 3 个 Skill 升级为「定制 AI 员工」，形成高客单收入。

| 模块 | 内容 | 优先级 |
|------|------|:---:|
| 企业知识库接入 | 支持上传企业资料（资质 / 历史标书 / 产品资料 / 人员信息），RAG 检索 | P1 |
| 员工定制配置 | 角色人设、技能组合、权限边界、会话记忆（轻量） | P1 |
| AI 员工交付流程 | 交付清单 / 验收标准 / 培训 / 上线 SOP | P1 |
| 服务费计费 | ¥500~5,000/月 服务费，纳入 Billing 订阅 | P1 |
| 首个行业试点 | 工程行业「AI投标员工」打样（¥9,800 / ¥29,800） | P1 |

### 4.3 B3 — 行业解决方案（6~12个月）【P2】

**目标**：以 1 个行业深挖，打包多 Agent + 私有化 + 运维，做大单。

| 模块 | 内容 | 优先级 |
|------|------|:---:|
| 行业方案组合 | 工程：AI投标+AI合同+AI项目管理+AI知识库+AI经营分析 | P2 |
| 私有化部署 | Docker Compose 一键部署到客户环境（现有 compose 基础上抽象） | P2 |
| 实施服务定价 | 部署费 / 知识库整理 / Agent配置 / 系统集成 / 年度运维 15~25% | P2 |
| 交付团队 SOP | 一人公司可执行的交付流水线 | P2 |

## 5. 技术规划要点

### 5.1 架构影响

```
现有：User → Gateway → Router → Provider
升级：User → Portal/API → Gateway → Skill Runtime(轻量Agent) → Router → Provider
                            │
                            ├─ Skill 定义（提示词+表单+模型配置）
                            ├─ Skill 实例（用户购买后的运行会话）
                            └─ Knowledge（B2 引入，RAG）
```

### 5.2 新增数据模型（B1）

| 表 | 说明 |
|----|------|
| skills | Skill 定义：名称 / 描述 / 图标 / 类型 / 定价 / 状态 / 版本 |
| skill_versions | 版本：系统提示词 / 表单 schema / 模型配置 / changelog |
| skill_instances | 用户购买实例：owner / skill / 订阅到期 / 用量 |
| skill_orders | 购买订单（复用或扩展 billing orders） |

### 5.3 关键约束

- MVP 阶段 Skill 运行时基于现有 Chat 链路实现，**不引入完整 Agent Runtime**，避免过度设计。
- Skill 计费复用现有 Billing 体系，不重复造轮子。
- RAG / 知识库（B2）按需引入向量检索，B1 不做。

## 6. 里程碑与验收

| 里程碑 | 交付物 | 验收标准 |
|--------|--------|---------|
| M1（B1 第 1 月） | Skill 数据模型 + CRUD API + Admin 管理 | API 契约评审通过，Admin 可发布/下架 Skill |
| M2（B1 第 2 月） | Skill 商城前端 + 计费打通 + 首批 3 个 Skill | 用户可购买并在线使用 Skill，订单计费正确 |
| M3（B1 第 3 月） | 5~10 个 Skill 全量上线 + 版本管理 | 至少 1 个 Skill 产生付费转化，回收用户反馈 |
| M4（B2 第 1 月） | AI 员工数据模型 + 知识库接入 | 上传企业资料后可检索回答 |
| M5（B2 第 3 月） | AI投标员工产品化交付 | 完成 1 个种子客户交付并验收 |
| M6（B3 末期） | 行业方案 + 私有化部署包 | 完成 1 个行业方案报价与试点 |
