## 2. 通用约定

### 认证方式

| 方式 | 适用场景 | Header |
|------|---------|--------|
| JWT Bearer Token | 管理后台接口 | `Authorization: Bearer <jwt_token>` |
| API Key | 模型 API 调用接口 | `Authorization: Bearer <api_key>` |

### 响应格式

```json
{
    "code": 0,
    "message": "success",
    "data": { ... },
    "traceId": "trace-xxx"
}
```

### 错误响应格式

```json
{
    "code": "ERROR_CODE",
    "message": "错误描述",
    "detail": {
        "field": "field_name",
        "reason": "具体原因"
    },
    "traceId": "trace-xxx"
}
```

### 通用错误码

| Error Code | HTTP Status | 说明 |
|:----------:|:-----------:|------|
| 0 | 200 | 成功 |
| AUTH001 | 401 | 未提供认证信息 |
| AUTH002 | 401 | 认证信息无效/已过期 |
| AUTH004 | 403 | 无权限 |
| VALID001 | 400 | 参数校验失败 |
| NOTFOUND | 404 | 资源不存在 |
| CONFLICT | 409 | 资源冲突（如邮箱已存在） |
| RATE001 | 429 | 请求频率超限 |
| QUOTA_EXCEEDED | 402 | 额度不足 |
| INTERNAL | 500 | 服务器内部错误 |

### 分页格式

请求参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|:-----:|------|
| page | integer | ❌ | 1 | 页码，从 1 开始 |
| pageSize | integer | ❌ | 20 | 每页数量，最大 100 |
| sortBy | string | ❌ | created_at | 排序字段 |
| sortOrder | string | ❌ | desc | 排序方向 (asc / desc) |

响应：

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "items": [],
        "pagination": {
            "page": 1,
            "pageSize": 20,
            "total": 100,
            "totalPages": 5
        }
    },
    "traceId": "trace-xxx"
}
```

## 3. 学生管理 API

### 3.1 创建学生账号

Admin 在后台创建学生账号。

```
POST /api/v1/admin/users
```

#### Authorization

`admin:user:create`

#### Request Body

```json
{
    "email": "student@example.com",
    "password": "securePassword123",
    "nickname": "张三"
}
```

| 字段 | 类型 | 必填 | 验证规则 | 说明 |
|------|------|:----:|---------|------|
| email | string | ✅ | 邮箱格式，最大 255 字符 | 学生登录邮箱 |
| password | string | ✅ | 最小 8 字符，最大 128 字符 | 登录密码 |
| nickname | string | ✅ | 最大 100 字符 | 学生昵称 |

#### Response (201)

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "id": 1,
        "email": "student@example.com",
        "nickname": "张三",
        "role": "Student",
        "quotaBalance": "0.000000",
        "status": "active",
        "apiKey": {
            "prefix": "sk-campus-a1b2c3",
            "createdAt": "2026-07-25T10:00:00Z"
        },
        "createdAt": "2026-07-25T10:00:00Z"
    }
}
```

#### Error Codes

| Error Code | HTTP Status | 场景 |
|:----------:|:-----------:|------|
| CONFLICT | 409 | 邮箱已存在 |
| VALID001 | 400 | 参数校验失败 |
| AUTH004 | 403 | 无 admin:user:create 权限 |

### 4.2 角色 CRUD

```
GET    /api/v1/admin/roles        # 角色列表
POST   /api/v1/admin/roles        # 创建角色
GET    /api/v1/admin/roles/{id}   # 角色详情
PUT    /api/v1/admin/roles/{id}   # 更新角色
DELETE /api/v1/admin/roles/{id}   # 删除角色
```

#### Authorization

`admin:role:manage`

#### GET /api/v1/admin/roles

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "roles": [
            {
                "id": 1,
                "name": "Admin",
                "description": "系统管理员，拥有全部管理功能权限",
                "isSystem": true,
                "permissions": ["dashboard:view", "admin:user:create", "..."],
                "createdAt": "2026-07-25T10:00:00Z"
            },
            {
                "id": 2,
                "name": "Student",
                "description": "学生用户，仅能使用 API 和查看个人用量",
                "isSystem": true,
                "permissions": ["dashboard:view", "api_key:manage", "billing:view_self"],
                "createdAt": "2026-07-25T10:00:00Z"
            }
        ]
    }
}
```

#### POST /api/v1/admin/roles

```json
{
    "name": "Teacher",
    "description": "教师角色",
    "permissionIds": [1, 2, 5]
}
```

| 字段 | 类型 | 必填 | 验证规则 | 说明 |
|------|------|:----:|---------|------|
| name | string | ✅ | 最大 100 字符，唯一 | 角色名称 |
| description | string | ❌ | 最大 255 字符 | 角色描述 |
| permissionIds | array | ❌ | | 权限 ID 列表 |

#### PUT /api/v1/admin/roles/{id}

```json
{
    "name": "Teacher",
    "description": "教师角色（更新）",
    "permissionIds": [1, 2, 5, 6]
}
```

#### DELETE /api/v1/admin/roles/{id}

- 系统内置角色（is_system = true）不可删除，返回 400
- 如果有用户正在使用该角色，返回 409 Conflict

#### Response (204)

删除成功返回 204 No Content。

## 7. Permission Middleware 集成说明

### 路由-权限码映射表

每个受保护的路由在注册时需要关联一个权限码。示例：

| 路由 | Method | 权限码 | 说明 |
|------|--------|--------|------|
| `/api/v1/admin/users` | GET | `admin:user:list` | 查看学生列表 |
| `/api/v1/admin/users` | POST | `admin:user:create` | 创建学生 |
| `/api/v1/admin/users/{id}/quota` | GET | `admin:user:manage_quota` | 查看额度 |
| `/api/v1/admin/users/{id}/quota` | PUT | `admin:user:manage_quota` | 设置额度 |
| `/api/v1/admin/users/{id}/models` | GET | `admin:user:manage_models` | 查看模型授权 |
| `/api/v1/admin/users/{id}/models` | PUT | `admin:user:manage_models` | 设置模型授权 |
| `/api/v1/admin/users/{id}/status` | PUT | `admin:user:manage` | 启用/禁用账号 |
| `/api/v1/admin/roles` | GET | `admin:role:manage` | 角色列表 |
| `/api/v1/admin/roles` | POST | `admin:role:manage` | 创建角色 |
| `/api/v1/admin/roles/{id}` | GET | `admin:role:manage` | 角色详情 |
| `/api/v1/admin/roles/{id}` | PUT | `admin:role:manage` | 更新角色 |
| `/api/v1/admin/roles/{id}` | DELETE | `admin:role:manage` | 删除角色 |
